# 관리자 기본 화면

## 구현 범위

- `/admin`에 로그인 계정과 관리자 권한을 보여주는 기본 화면을 제공합니다.
- 왼쪽 메뉴의 마지막 항목에 남색 관리자 메뉴를 표시합니다. `ROLE_ADMIN` 계정에서만 보입니다.
- `/admin`과 `/admin/**`는 주소를 직접 입력해도 관리자만 접근 가능합니다. 비로그인은 로그인 화면, 일반 회원은 기존 접근 거부 화면으로 이동합니다.
- `AdminController`에도 관리자 권한 검사를 적용합니다. 기존 로그인·리뷰 보안·CSRF 설정은 유지합니다.
- 식단 등록, 회원·리뷰 관리, 서버 통계 기능은 이번 기본 화면에 포함하지 않습니다.

## 테이블과 권한

변수명 정의서의 `tbl_member(userid)`와 `tbl_member_auth(userid, auth)`를 그대로 사용합니다. 두 테이블은 [공통 DB SQL](sql/install/01_database.sql)에 있으므로 별도 관리자 테이블을 만들지 않습니다.

기존 계정에 관리자 권한이 없다면 [01_grant_admin.sql](sql/admin/01_grant_admin.sql)의 `v_userid`를 실제 관리자 아이디로 바꾸고 F5로 실행합니다. 기본값은 `admin0`입니다. 계정은 미리 존재하고 활성화되어 있어야 하며, 로그인 가능한 비밀번호와 계정 상태는 별도 준비해야 합니다.

이 SQL은 해당 계정에 `ROLE_ADMIN`을 추가하고 커밋합니다. 비밀번호나 기존 권한은 변경하지 않습니다. 이미 같은 권한이 있으면 추가하지 않습니다. 기존 권한이 중복돼 있으면 중단합니다. 적용 후 로그아웃하고 다시 로그인해야 새 권한이 반영됩니다. 실제 DB에는 자동 실행하지 않습니다.

## 확인 방법

1. 비로그인 상태에서 `/admin` 접근: 로그인 안내, 관리자 메뉴 숨김.
2. 일반 회원 로그인 후 직접 접근: 접근 거부, 관리자 메뉴 숨김.
3. 관리자 로그인: 왼쪽 마지막 남색 메뉴 표시, 관리자 화면에서 자신의 아이디 확인.
4. `/admin/`과 하위 경로도 일반 계정 접근 차단. 아직 없는 하위 화면은 관리자라도 페이지가 제공되지 않습니다.
5. 모바일에서 메뉴 펼침과 관리자 링크 이동 확인.

검증: Java 전체 컴파일과 JUnit 38개, 기존 SQL/메뉴 팝업/홈 애니메이션 검사 통과. 관리자 접근·비관리자 차단·CSRF는 실제 Spring Security 설정을 로드한 테스트로 확인했습니다. Maven 대신 JDK 15와 로컬 의존성으로 검사했으며 로그는 `ex06_2/target/admin-check`에 있습니다.

실제 DB 권한 부여와 브라우저 화면 검증은 미실시입니다. Clean 빌드 후 Tomcat에 배포하세요.
