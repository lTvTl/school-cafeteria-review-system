# 📋 학교식당 리뷰 시스템 변수명 및 테이블 정의서

본 문서는 요구사항 정의서(`SFR-001` ~ `SFR-010`, `INR-001` ~ `INR-002`, `SER-003` 등)를 바탕으로 팀원 간 **DB 컬럼명, Java(VO/DTO) 변수명, JSP/JS 파라미터명**을 통일하기 위해 작성되었습니다.

---

## 0. 네이밍 규칙 (Naming Convention)
1. **Java 변수 / JSP `name` 속성**: `camelCase` 사용 (예: `menuId`, `isMatched`, `starScore`)
2. **Oracle DB 테이블 / 컬럼명**: `snake_case` 사용, 테이블 접두사는 기존 프로젝트 규칙에 맞춰 **`tbl_`** 사용 (예: `tbl_menu`, `menu_id`)
   * *참고*: MyBatis에서 자동 매핑이 편하도록 기존 `tbl_board`(`regdate`, `updatedate`)처럼 단어 구분 없이 소문자로 쓰거나 `mapUnderscoreToCamelCase` 설정을 활용할 수 있습니다. 아래 표에는 가독성을 위해 DB 컬럼과 Java 변수명을 1:1로 매핑해 두었습니다.
3. **클래스명 (VO / DTO)**: `PascalCase` + 접미사 `VO` 또는 `DTO` (예: `MenuVO`, `MenuReviewVO`, `DailyDietVO`)
4. **[기존]** 표시가 된 변수는 현재 `ex06_2` 베이스 코드에 이미 구현된 변수이므로 **이름을 변경하지 않고 그대로 사용**합니다.
